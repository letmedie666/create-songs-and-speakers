## Boombox as a radio
Switch the Boombox on (right-click in the air) and it plays the radio station it is tuned to from anywhere in your inventory,
like the Portable Radio. Sneak + right-click opens the tuner (frequency, volume). A normal right-click on a block places it
as before. There has to be a Music Manager or Cassette Deck with a Parabolic Antenna playing on the same frequency.
